# Rally Together

I want to create a web booking app for community sports meetups. It should have a system for users to set up sessions, users to join those sessions and see the details and allow for the embeddings of users social networks such as instagram, etc... It should also have google maps embeddings for the locational services. Users can make accounts using email or gmail (gmail auth sign in using google services).
